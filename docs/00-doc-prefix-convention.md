# Doküman önekleri (L0–L4)

| Önek | Tipik içerik |
|------|----------------|
| `00-` | Giriş, indeks, kısa kural |
| `10-` | Meta, plan özeti |
| `20-` | Bağlayıcı kurallar (rules) |
| `30-` | Spec / sprint (kullanımda değilse oluşturmayın) |
| `40-` | Nasıl yapılır (guide) |
| `41-` | Referans (seed kullanıcı vb.) |
| `42-` | Tasarım / UI rehberi |

Dosya adı: `{tier}-{kategori}-{sıra}-{kısa-baslik}.md` (ör. `20-rules-001-product-scope.md`).
